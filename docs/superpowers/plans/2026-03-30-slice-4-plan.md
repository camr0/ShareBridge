## Task 1 — Server: support `preferred_code` in session creation

**Files:**
- `signaling-server/internal/session/manager.go`
- `signaling-server/internal/handler/rest.go`

### 1a. `session/manager.go`

Add `isCodeTaken` helper and update `Create` signature:

```go
// isCodeTaken returns true if the code is in use by a different token.
// Same token re-registering the same code is allowed.
func (m *Manager) isCodeTaken(code, token string) bool {
    m.mu.RLock()
    defer m.mu.RUnlock()
    s, ok := m.sessions[code]
    return ok && s.Token != token && time.Now().Before(s.ExpiresAt)
}
```

Update `Create` signature from:
```go
func (m *Manager) Create(token, shareURL string, ttl time.Duration) (*Session, error)
```
to:
```go
func (m *Manager) Create(token, shareURL, preferredCode string, ttl time.Duration) (*Session, error)
```

Logic inside `Create`:
```go
code := preferredCode
if code == "" || m.isCodeTaken(code, token) {
    if code != "" {
        log.Printf("warning: requested code %s is already taken, assigning new code", code)
    }
    var err error
    code, err = generateCode()
    if err != nil {
        return nil, fmt.Errorf("generate code: %w", err)
    }
}
// use code as session ID (rest of function unchanged)
```

## Task 2 — Agent: new `store` package

**New file:** `agent/internal/store/store.go`

```go
package store

import (
    "encoding/json"
    "fmt"
    "os"
    "path/filepath"
    "sync"
)

type sessionEntry struct {
    Code          string `json:"code"`
    DownloadCount int    `json:"download_count"`
}

type storeData struct {
    Sessions map[string]sessionEntry `json:"sessions"`
}

type Store struct {
    mu       sync.Mutex
    filePath string // full path to sessions.json
}

// New resolves the data directory (OPENCLOUDSHARE_DATA_DIR or ~/.opencloudshare),
// creates it if needed, and returns a Store. Returns error if dir cannot be created
// or if sessions.json exists but is malformed.
func New() (*Store, error) {
    dataDir := os.Getenv("OPENCLOUDSHARE_DATA_DIR")
    if dataDir == "" {
        homeDir, err := os.UserHomeDir()
        if err != nil {
            return nil, fmt.Errorf("resolve home dir: %w", err)
        }
        dataDir = filepath.Join(homeDir, ".opencloudshare")
    }
    if err := os.MkdirAll(dataDir, 0700); err != nil {
        return nil, fmt.Errorf("create data dir %s: %w", dataDir, err)
    }
    store := &Store{filePath: filepath.Join(dataDir, "sessions.json")}
    // Validate existing file is parseable (fail fast rather than silently overwrite)
    if _, err := store.load(); err != nil {
        return nil, fmt.Errorf("sessions.json is malformed — fix or delete %s: %w", store.filePath, err)
    }
    return store, nil
}

func (store *Store) GetCode(shareURL string) string {
    store.mu.Lock()
    defer store.mu.Unlock()
    storeData, _ := store.load()
    return storeData.Sessions[shareURL].Code
}

func (store *Store) SetCode(shareURL string, code string) error {
    store.mu.Lock()
    defer store.mu.Unlock()
    storeData, err := store.load()
    if err != nil {
        return err
    }
    entry := storeData.Sessions[shareURL]
    entry.Code = code
    storeData.Sessions[shareURL] = entry
    return store.save(storeData)
}

func (store *Store) GetDownloadCount(shareURL string) int {
    store.mu.Lock()
    defer store.mu.Unlock()
    storeData, _ := store.load()
    return storeData.Sessions[shareURL].DownloadCount
}

func (store *Store) IncrementDownloadCount(shareURL string) (int, error) {
    store.mu.Lock()
    defer store.mu.Unlock()
    storeData, err := store.load()
    if err != nil {
        return 0, err
    }
    entry := storeData.Sessions[shareURL]
    entry.DownloadCount++
    storeData.Sessions[shareURL] = entry
    if err := store.save(storeData); err != nil {
        return 0, err
    }
    return entry.DownloadCount, nil
}

// load reads sessions.json. Returns empty storeData if file doesn't exist.
// Returns error if file exists but is malformed JSON.
func (store *Store) load() (storeData, error) {
    result := storeData{Sessions: make(map[string]sessionEntry)}
    fileBytes, err := os.ReadFile(store.filePath)
    if os.IsNotExist(err) {
        return result, nil
    }
    if err != nil {
        return result, fmt.Errorf("read %s: %w", store.filePath, err)
    }
    if err := json.Unmarshal(fileBytes, &result); err != nil {
        return result, fmt.Errorf("parse %s: %w", store.filePath, err)
    }
    if result.Sessions == nil {
        result.Sessions = make(map[string]sessionEntry)
    }
    return result, nil
}

// save writes storeData to sessions.json atomically (write to temp file, rename).
// NOTE: sync.Mutex protects against concurrent access within this process only.
// A user editing sessions.json while the agent is running may have their changes
// silently overwritten on the next write. Full file locking (flock) is deferred
// to the daemon slice when multiple processes may write to the same file.
func (store *Store) save(storeData storeData) error {
    jsonBytes, err := json.MarshalIndent(storeData, "", "  ")
    if err != nil {
        return fmt.Errorf("marshal: %w", err)
    }
    tmpPath := store.filePath + ".tmp"
    if err := os.WriteFile(tmpPath, jsonBytes, 0600); err != nil {
        return fmt.Errorf("write %s: %w", tmpPath, err)
    }
    return os.Rename(tmpPath, store.filePath)
}
```

## Task 3 — Agent: wire `preferred_code` into `CreateSession`

**File:** `agent/internal/signaling/client.go`

Current signature:
```go
func (c *Client) CreateSession(ctx context.Context, shareURL, ttl string) (string, error)
```

Change to:
```go
func (c *Client) CreateSession(ctx context.Context, shareURL, preferredCode string) (string, error)
```

Update the request body marshaling:
```go
// Before
body, err := json.Marshal(map[string]string{"share_url": shareURL, "ttl": ttl})

// After
reqBody := map[string]string{"share_url": shareURL}
if preferredCode != "" {
    reqBody["preferred_code"] = preferredCode
}
body, err := json.Marshal(reqBody)
```

**Note:** The `ttl` parameter is dropped — the server default is used. This matches the Slice 3 decision that TTL is not a CLI concern yet.

## Task 5 — Agent: wire store into `main.go`

**File:** `agent/cmd/agent/main.go`

Add import: `"opencloudshare/agent/internal/store"`

In `runShare`, after loading config and creating the WebDAV client, initialise the store:

```go
st, err := store.New()
if err != nil {
    return fmt.Errorf("session store: %w", err)
}
```

Before the reconnect loop, load persisted state:
```go
preferredCode := st.GetCode(shareURL)
```

Update `runSession` call or pass `preferredCode` into it. Inside `runSession`, update the `CreateSession` call:
```go
// Before
code, err := sig.CreateSession(ctx, shareURL, "")

// After
code, err := sig.CreateSession(ctx, shareURL, preferredCode)
```

After the code is returned, persist it:
```go
if err := st.SetCode(shareURL, code); err != nil {
    return fmt.Errorf("save session code: %w", err)
}
```

When constructing the transfer manager, restore the download count from the store and wire the callback.
The store is the source of truth — `GetDownloadCount` is called every time a new manager is created (i.e. every time a browser connects), so the count is always current. The in-memory atomic is just for fast reads during the session; `OnDownloadComplete` keeps it in sync with the store after each download:
```go
tm := transfer.NewManager(p, webdavClient, cfg.Password, cfg.MaxDownloads)
// Restore persisted download count
tm.downloadCount.Store(int32(st.GetDownloadCount(shareURL)))
// Wire persistence callback
tm.OnDownloadComplete = func() {
    if _, err := st.IncrementDownloadCount(shareURL); err != nil {
        log.Printf("warning: could not persist download count: %v", err)
    }
}
```

**Note:** `tm.downloadCount` is an `atomic.Int32` — it's unexported. Either export it, add a `SetDownloadCount(n int)` method to `Manager`, or initialise it via `NewManager`. The cleanest approach is to add a `SetDownloadCount` method to `Manager`:

```go
// In manager.go
func (m *Manager) SetDownloadCount(n int) {
    m.downloadCount.Store(int32(n))
}
```

Then in `main.go`:
```go
tm.SetDownloadCount(st.GetDownloadCount(shareURL))
```
