### Task 4: Reliable Documentation-only Release Tags

**Files:**
- Modify: `.github/workflows/agent-container.yml:3-16`

- [ ] **Step 1: Add a static workflow regression check**

Create a temporary read-only assertion command for the desired trigger shape:

```bash
python3 - <<'PY'
from pathlib import Path
text = Path('.github/workflows/agent-container.yml').read_text()
assert 'tags:\n      - "v*"' in text
push = text.split('  push:', 1)[1].split('  workflow_dispatch:', 1)[0]
assert 'paths:' not in push
pull_request = text.split('  pull_request:', 1)[1].split('  push:', 1)[0]
assert 'paths:' in pull_request
PY
```

Expected before the edit: FAIL because the push event still has a `paths` filter.

- [ ] **Step 2: Change the event filter**

Update the workflow trigger to:

```yaml
on:
  pull_request:
    paths:
      - "agent/**"
      - ".github/workflows/agent-container.yml"
  push:
    branches:
      - main
    tags:
      - "v*"
  workflow_dispatch:
```

This intentionally runs all `main` pushes as well as all `v*` tags. GitHub Actions cannot express a path filter that applies to branches but not tags within one `push` event, and reliable release tags take priority over avoiding inexpensive no-op main builds.

- [ ] **Step 3: Re-run the static check and inspect YAML**

Run the Python assertion from Step 1 again, followed by:

```bash
git diff --check -- .github/workflows/agent-container.yml
git diff -- .github/workflows/agent-container.yml
```

Expected: assertions pass; pull requests remain path-filtered; pushes to `main` and `v*` tags are unfiltered.

- [ ] **Step 4: Commit**

```bash

git commit -m "ci: publish agent for every release tag"
```
